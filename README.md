# Battleship Console Game
A two-player Battleship game built in C# to practice object-oriented programming and core .NET concepts.

## Features
- Player ship placement
- Input validation
- Hit and miss detection
- Turn-based gameplay
- Winner detection

## Technologies
- C#
- .NET
- Console Application

## Purpose
This project was created as part of learning C# fundamentals, including:
- Classes and Objects
- Lists
- Loops
- Methods
- Input Validation
- Basic Project Structure
